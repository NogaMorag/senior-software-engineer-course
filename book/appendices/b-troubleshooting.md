# נספח ב: פתרון תקלות

הנספח הזה מרכז במקום אחד את התקלות שהפרקים והתרגילים כבר תיארו: טבלאות התקלות של פרק 2, רשימות „טעויות
נפוצות” של הפרקים, ורשימות „טעויות נפוצות ותיקונים” של ה־README בכל תרגיל. הוא לא מוסיף תקלות חדשות. כל שורה
מפנה למקור שלה, ושם יש את ההקשר המלא.

לפני שמחפשים כאן, הסדר של פרק 2, סעיף 2.11: לקרוא את השורה האחרונה של השגיאה עד הסוף, לבדוק איפה את (`pwd`),
לבדוק איזה עותק של הכלי ירוץ (`command -v`), לפתוח לשונית חדשה, ולהריץ את הרופא. רוב התקלות הן אחת משלוש:
הפקודה לא נמצאת, נמצאת גרסה אחרת, או שאת בתיקייה הלא נכונה.

העמודה „פרק” מפנה כך:

| הצורה | הפירוש |
| --- | --- |
| 2.4 | פרק 2, סעיף 2.4 |
| 21, טעויות | הרשימה „טעויות נפוצות” בסוף פרק 21 |
| 21, תרגיל | הרשימה „טעויות נפוצות ותיקונים” ב־README של תרגיל פרק 21 |

הסדר: WSL2 והטרמינל, Docker Desktop, Go, uv ו־Python, PostgreSQL, Redis, Redpanda, kind ו־kubectl, Helm,
Terraform, GitHub Actions, מחסנית התצפיתיות, k6 ו־testcontainers, Rust, ובסוף Mac ואיך מבקשים עזרה.
