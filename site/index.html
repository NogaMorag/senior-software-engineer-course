מהנדסת תוכנה בכירה בתעשייה: ספר לימוד ותוכנית למידה

ספר לימוד בעברית למפתחת מנוסה שמכוונת לתפקיד backend או תשתיות בכיר בשוק הישראלי של סוף 2026. Go מאפס ועד הרגלי ייצור, Python ברמה בכירה, יסודות backend ומערכות מבוזרות, Kubernetes, תצפיתיות, אבטחה, אומנות הבכירות והכנה לראיונות. הספר בנוי סביב קוד שרץ באמת, ומסתיים בפרויקט תיק עבודות: Hookline, פלטפורמה למסירת webhooks.

איך קוראים: הדרך הנוחה היא גרסת ה־HTML בתיקייה site/. אפשר גם לפתוח את התיקייה book/ ב־Obsidian עם התוסף RTL Support. לוח הלימוד היומי נמצא בנספח ו, ובאנגלית בקובץ 00-stage1/05-daily-schedule.md.
