# תרגיל פרק 34: הכנה לתהליך הגיוס

**מטרה:** לצאת מהיום עם שלושה מסמכים שלך, מוכנים לשימוש: חמישה סיפורים התנהגותיים כתובים ומתורגלים בקול (אחד
מהם על Hookline), קורות חיים שעברו את רשימת הבדיקה, ודף משא ומתן עם טווח שכר מבוסס ותשובה מוכנה לשאלה על
הציפיות. זה תרגיל בלי קוד: אין בדיקות אוטומטיות ואין פתרון, כי החומר הוא הניסיון שלך.

**זמן משוער:** יום לימוד אחד, יום 93, כ־55 דקות עבודה: כ־30 לסיפורים, כ־15 לקורות החיים וכ־10 לדף המשא ומתן.
הסיפורים לא נגמרים ביום אחד; את תחזרי אליהם לפני כל ראיון.

**ידע מקדים:** פרק 34 כולו. מפרק 1: מטריצת הפערים שמילאת (התרגיל `ch01-reading-postings`) ומודעות הדרושים
ששמרת. מפרויקט הגמר: הקובץ `docs/EVALUATION.md` שלך, אם כבר יש בו מספרים שמדדת (אבן הדרך האחרונה, M10, מגיעה
בימים 98 ו־99; עד אז השאירי את השדות האלה ריקים). צריך עורך טקסט ושעון עצר; הטלפון מספיק.

| קובץ | תפקיד |

| `templates/take-home-readme.md` | שלד README באנגלית למטלת בית, לפי סעיף 34.4; לשימוש במטלה אמיתית |

## צעדים

**1. העתיקי את התבניות** לתיקייה של הפרק:

<div dir="ltr" align="left">

```bash
mkdir -p ~/senior-course/ch34
cp "$COURSE"/exercises/ch34-interview-loop/templates/*.md ~/senior-course/ch34/
ls ~/senior-course/ch34
```

</div>

**2. בחרי חמישה מקרים** (כ־5 דקות). רשמי כותרת אחת לכל אחד בטבלת הכיסוי של `stories.md`, וסמני אילו
סימנים הוא מראה: היקף, עמימות, קונפליקט, כישלון, השפעה. אחד מהחמישה הוא Hookline. אם עמודה נשארת ריקה,
החליפי מקרה. הרשימה בסעיף 34.3 עוזרת להיזכר.

**3. כתבי את הסיפורים** (כ־15 דקות). לכל אחד: מצב, משימה, פעולה, תוצאה, ומה היית עושה אחרת. נקודות, לא
פסקאות; את לא תקראי את זה בראיון, את תספרי. כל מספר שאת כותבת צריך להיות מספר שאת יודעת; אם לא, כתבי
„לא ידוע”. בסיפור של Hookline מלאי קודם את שני השדות של הכנות: מה כתבת בעצמך, ומה מדדת.

**4. ספרי כל סיפור בקול, עם שעון** (כ־10 דקות, כל החמישה). היעד: עד שלוש דקות. רשמי את הזמן
בשדה שלו. אם עברת, קצרי את המצב, לא את הפעולה.

**5. עברי על קורות החיים** עם `cv-checklist.md` (כ־15 דקות). תקני כל שורה שלא עוברת, או רשמי לידה למה היא
נשארת. כתבי את סעיף הפרויקט של Hookline לפי סעיף 34.5.

**6. מלאי את דף המשא ומתן** (כ־10 דקות). העתיקי את הטווח מהטבלה של סעיף 34.6 עם המקור והתאריך, הוסיפי מקור
אחד שבדקת בעצמך היום, וכתבי מילה במילה את התשובה שלך לשאלה „מה הציפיות שלך?”. אמרי אותה בקול פעמיים.

**7. שמרי את העבודה:**

<div dir="ltr" align="left">

```bash
cd ~/senior-course
git add ch34
git commit -m "Chapter 34: stories, CV checklist, negotiation sheet"
```

</div>

> **שימי לב:** אם המאגר `~/senior-course` שלך ציבורי, דף המשא ומתן וקורות החיים לא צריכים להיות בו. שמרי
> אותם מחוץ למאגר, או במאגר פרטי.

## רשימת בדיקה

- [ ] חמישה סיפורים, לכל אחד מצב, משימה, פעולה, תוצאה ו„מה הייתי עושה אחרת”.
- [ ] כל אחד מחמשת הסימנים מכוסה בשני סיפורים לפחות.
- [ ] כל סיפור סופר בקול בפחות משלוש דקות, והזמן רשום.
- [ ] בכל סיפור, הפעולה מתוארת בגוף ראשון, ומה שעשה הצוות מתואר כעבודת הצוות.
- [ ] אין בסיפורים פרט פנימי של מעסיק.
- [ ] בסיפור של Hookline כתוב מה כתבת בעצמך ומה קיבלת מהקורס, ויש בו רק מספרים שמדדת.
- [ ] קורות החיים עברו את `cv-checklist.md`, ושורות שלא עברו מוסברות.
- [ ] בדף המשא ומתן יש טווח עם מקור ותאריך, ולא מספר יחיד.

## טעויות נפוצות ותיקונים

- **„אנחנו” לאורך כל הסיפור.** המראיינת לא יודעת מה עשית את. כתבי מחדש את הפעולה בגוף ראשון, והשאירי
  „אנחנו” רק במצב.
- **סיפור של שבע דקות.** כמעט תמיד המצב ארוך מדי. שלושה משפטים של רקע, ואז ישר למה שעשית.
- **מספר שאת לא בטוחה בו.** „שיפרתי ב־40%” בלי לדעת איך נמדד יתפרק בשאלת ההמשך הראשונה. כתבי מה ראית,
  ואיך, או ותרי על המספר.
- **אין סיפור כישלון.** מראיינים שואלים עליו כמעט תמיד. בחרי כישלון אמיתי שאת יכולה לספר עליו בשקט, עם מה
  שתיקנת אחריו.
- **מספר יחיד בדף המשא ומתן.** מספר יחיד נשמע כמו מחיר סופי, ואין לו מקור. טווח, עם המקור והתאריך שלו.

## רמזים

- כדי להיזכר במקרים, עברי על הודעות commit, תחקירים, מסמכי תכנון ופגישות רטרו שלך מהשנים האחרונות.
- אם קשה למצוא סיפור „קונפליקט”, חפשי מקרה שבו לא הסכמת עם החלטה טכנית. הסיפור הוא איך טיפלת באי־ההסכמה.
- הקליטי את עצמך פעם אחת. בהאזנה תשמעי איפה את מתנצלת, איפה את ממהרת, ואיפה חסר מספר.
- לסיפור של Hookline, פתחי את פרק 37 ואת טבלת ההחלטות שלו. בחרי החלטה אחת שאת יכולה להגן עליה, וחלופה שדחית.

## הפתרון

אין פתרון, וזה בכוונה: אין דרך לכתוב בשבילך את הסיפורים שלך, וכל דוגמה „מוכנה” הייתה מפתה להשתמש בה. מה שיש
הוא הבדיקה: הרשימה למעלה, והשאלות בסוף פרק 34. אם תענייני על כל אחת מהן בקול, עם אחד מחמשת הסיפורים, בתוך
שלוש דקות, העבודה גמורה.

## מה התרגיל מדגים

- הכנה התנהגותית כעבודה כתובה ומתורגלת, לא כאלתור ביום הראיון.
- כיסוי שיטתי של הסימנים שמראיינים מחפשים אצל בכירה.
- קורות חיים שבהם כל טענה ניתנת להוכחה בשיחה.
- משא ומתן שמבוסס על טווח, מקור ותאריך, ולא על מספר אחד.
- כלל הכנות בפועל: מה עשית, מה מדדת, ומה קיבלת מאחרים.
