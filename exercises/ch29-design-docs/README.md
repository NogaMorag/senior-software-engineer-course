# תרגיל פרק 29: `design-docs`, מחשבון הערכה, מסמך תכנון ורשומת החלטה

**מטרה:** להשלים את `sizing`, מחשבון קטן שהופך קובץ הנחות בפורמט TOML לבקשות בשנייה, אחסון ורוחב פס, עם
הבדיקות שלו; ואז לכתוב בתבנית מסמך תכנון אחד להרחבה של Hookline לבחירתך, עם רשומת החלטה (ADR) אחת. המחשבון הוא
כלי שתחזרי אליו בכל מסמך ובכל ראיון תכנון.

**זמן משוער:** יום לימוד אחד, יום 88: כ־20 דקות למחשבון, וכ־35 דקות למסמך ולרשומה.

**ידע מקדים:** פרק 29; פרק 7 (פרויקט uv והכלים שלו: בדיקות, לינטר ובודק טיפוסים); פרק 37 (המפרט של Hookline,
שהמסמך שלך מרחיב). התרגיל לא מייבא קוד מתרגילים קודמים, ומשתמש רק בספרייה הסטנדרטית של Python ‏(`tomllib`). הגרסאות
של כלי הפיתוח מקובעות ב־`pyproject.toml` (נכון לאוקטובר 2026, ראי נספח ג).

| פונקציה | מה היא מחזירה |
| --- | --- |
| `qps` | בקשות ביום חלקי `SECONDS_PER_DAY`; השיא הוא הממוצע כפול `peak_factor` |
| `writes` | הקצב של `qps` כפול `per_request` של הרשומה |

| `retained_bytes` | סכום של `bytes_per_day` כפול ימי השמירה, ועוד אינדקסים, כפול מספר העותקים |
| `bandwidth` | סכום הבתים לבקשה בכל התעבורות, כפול `qps` |
| `human_bytes` | מחרוזת בחזקות של 1024, למשל `1.5 KiB`; בתים שלמים בלי נקודה עשרונית |

## טעויות נפוצות ותיקונים

- **‏`test_human_bytes_uses_powers_of_two` נכשלת על `1024.0 PiB`.** הלולאה עוצרת בגלל חוסר ביחידות במקום להישאר
  ביחידה האחרונה. ראי איך `human_bits_per_second` מטפלת ביחידה האחרונה, ועשי אותו דבר.
- **‏`0 B` מודפס כ־`0.0 B`.** בתים הם שלמים; רק מ־KiB ומעלה יש ספרה אחרי הנקודה. הבדיקה בודקת את שתי הצורות.
- **‏`retained_bytes` גדול פי מספר הרשומות.** הכפלת באינדקסים ובעותקים בתוך הסכום ובחוץ. הסכום הוא של הנתונים הגולמיים
  בלבד, וההכפלות פעם אחת אחריו.
- **‏mypy מתלונן על טיפוס מספרי.** כל המספרים במודל הם `float`, חוץ ממספר העותקים, שהוא `int`. חילוק ב־`/`
  מחזיר תמיד `float`, וזה מה שרוצים.
- **הבדיקה שלך לא רצה, והמספר נשאר 27.** הקובץ נמצא מחוץ לתיקייה `tests/`, ו־pytest מחפש רק בה. זו ההגדרה
  `testpaths` בקובץ הפרויקט. העבירי אותו פנימה, ושמרי על שם שמתחיל ב־`test_`.

## רמזים

- ‏`SECONDS_PER_DAY` כבר מוגדר בראש הקובץ, וגם `Rate`. ‏`writes` יכולה לקרוא ל־`qps`.
- ב־`retained_bytes` מספיק סכום אחד על כל הרשומות, ואחריו שתי הכפלות. ערך של 0.5 לאינדקסים פירושו כפול 1.5.
- ב־`human_bytes` יש שתי צורות הדפסה. לבתים `f"{n:.0f} {unit}"`, ולשאר `f"{n:.1f} {unit}"`.
- בבדיקה שלך, בני את הנתיב לקובץ ההנחות מהמיקום של קובץ הבדיקה, `Path(__file__)`, ולא מהתיקייה שממנה מריצים.
- במסמך: התחילי מהלא־מטרות. הן הכי קשות לכתיבה, והן אלה שמונעות ויכוחים בסקירה.

## הפתרון

של עשר לרשת מונעת טעות נפוצה מאוד בהערכות: בלבול של פי שמונה בין בתים לביטים.
