# Hookline documentation

The specification is chapter 37 of the book (`book/37-hookline-spec.md`); the milestones are chapter 38.
This directory collects what the project produces along the way:

| File | Milestone | Content |
| --- | --- | --- |
| `runbooks/*.md` | M8 | one runbook per alert (TEMPLATE.md for new ones) |
| `postmortem-TEMPLATE.md`, `postmortem-2026-10-05.md` | M8 | the template, and the staged incident's postmortem: the author's run, labelled, and blanks for yours |
| `threat-model.md` | M9 | threats, mitigations, and the tests that prove them |
| `EVALUATION.md` | M6, M9, M10 | one section per target N1 to N9: tables for your runs, with date and machine, and the author's runs, labelled |
| `DEMO.md` | M10 | the 10-minute demo script: what to show, the command, what to say |
